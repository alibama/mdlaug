  • significant after false-discovery correction across all {{N_TESTS}} tests;
  • significant when platforms are compared only within the same type of institution;
  • still significant without Digital Commons, unless the claim is about Digital Commons itself;
  • the same platform ordering appears in run {{REP_ID}}, an earlier {{REP_DEVICE}} crawl of {{N_REPLICATE}} sites (Spearman ρ ≥ 0.6); where that run has no such measure, q < 0.01 instead.

Method

Unit of analysis: one site. Primary sample: crawl run {{RUN_ID}} ({{RUN_DEVICE}} emulation, {{N_PRIMARY}} sites with a loaded home page; {{N_VERIFIED}} of them vendor-verified). {{PATCH_NOTE}} Replication sample: run {{REP_ID}} ({{REP_DEVICE}}, {{N_REPLICATE}} sites, {{N_BOTH}} in both runs). Because the two runs mostly cover the same sites, replication shows the result isn't an artifact of the device or crawler version. It is not an independent sample. Pages that turned out to be bot-protection challenges are left out.

Evidence used: axe-core WCAG 2.2 A/AA rules, deterministic probes, and mDLAUG engine scorecards with confidence ≥ 0.7, not flagged for review, and not in an always-review situation (USE1, ACC3/COM4, FIL3/HEP1, RED4). LLM judgments were left out. Overlay measures come from the crawler's overlay pass, taken before each overlay was dismissed. Results-page measures cover only sites whose search reached results.

Tests: permutation Kruskal–Wallis (counts and scores) or chi-square (yes/no), {{N_PERM}} permutations; a stratified permutation that shuffles platform only within library type (and the reverse); and, for platform, the same test without Digital Commons. Benjamini–Hochberg FDR runs across all {{N_TESTS}} tests. Per-platform "differs" flags come from one-vs-rest Mann–Whitney or Fisher tests with their own FDR. Effect sizes are ε² (Kruskal–Wallis) or Cramér's V.

Reproduce with python scripts/significance.py then python scripts/significance_report.py. Per-site tables and every test are in data/significance/.
