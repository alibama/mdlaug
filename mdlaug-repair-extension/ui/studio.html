mDLAUG Conversion Studio

PDF and Word documents into accessible, screen-reader-friendly formats — entirely on your device.

Drop a file here or choose one — PDF, DOCX, CSV or TXT.

Conversions run locally with vendored pdf.js/mammoth — nothing is uploaded. Scanned/image-only PDFs need OCR (not bundled).

Reading Room & compute

The Reading Room re-presents any page in one standardized, screen-reader-first layout. Heavy jobs (describing images/graphs, reflowing files, OCR) run through a budgeted queue. Nothing here is required — with no description service set, missing descriptions are simply flagged.

A POST endpoint that accepts { image, prompt } and returns { description } (or an OpenAI-style choices[].message.content). The image URL is sent to this service, so use one you trust — ideally self-hosted. Leave blank to keep descriptions flag-only.

Site packs

Site packs add platform-specific fixes on top of the generic rules, applied only on matching sites. Bundled packs load automatically. You can add your own as declarative JSON — no code, just a selector and the attributes to set. See docs/SITE-PACKS.md.

Assessment storage

Assessments save with no setup by default — straight to a local database in this browser, using the same schema as Turso. Point it at a Turso database only when you want to centralize or share results; nothing else changes.

The token is a database credential, kept only on this device (chrome.storage.local, never synced) and sent straight to your database endpoint. For a shared deployment, front Turso with a thin relay and point the URL at the relay. Tip: turso dev --db-file mdlaug.db starts a local server at http://127.0.0.1:8080 and the schema is created automatically on first save.
