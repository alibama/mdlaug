mDLAUG audit

How to score each situation (1–7)

Rate how fully the library meets the guidelines for each situation:

  • 1 — Non-compliance: the guideline is essentially unmet; a screen-reader user is blocked.
  • 2: severe, pervasive problems.
  • 3: major gaps; the task is possible but difficult.
  • 4: partial — a mix of compliant and non-compliant elements.
  • 5: mostly compliant; a few minor issues.
  • 6: compliant with only negligible nits.
  • 7 — Full compliance: consistently meets the guideline.

The suggested score is a starting point from what the tool could detect automatically — adjust it using your own review with a screen reader.
