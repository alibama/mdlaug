    02 · The conversion studio · ACC1 / ACC2 / ACC3

    A downloaded PDF is a dead end for a screen reader. Reflow it into a live, semantic document — right here, nothing uploaded.

    Drop a file or choose one — PDF, DOCX, CSV, or TXT.

    Honest scope: text PDFs reflow cleanly; scanned/image-only PDFs need OCR (a hook is provided, not bundled). Heading detection is font-size heuristic, so a borderline sub-head can read as body text. DOCX→PDF is left to the browser's own print-to-PDF to avoid silent fidelity loss.
    Repair engine and converter are the same framework-free modules that ship in the browser extension — one source of truth. Built against the public mDLAUG guidelines. Independent project — not affiliated with or endorsed by the guidelines' authors. pdf.js is Apache-2.0; mammoth is BSD-2-Clause.
